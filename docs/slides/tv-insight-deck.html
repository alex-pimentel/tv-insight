The one decision everything follows from

Clean Architecture, four layers, with the dependency rule enforced by import direction.

Nothing points outward. The domain imports only the standard library.

# verify it in ten seconds grep -rn "^import\|^from" \ src/tv_insight/domain \ | grep -v tv_insight
presentation → application → domain (nothing points outward) infrastructure ─────────────┘

That is why the domain tests need no database, no HTTP and no fixtures — and run in milliseconds.

A port, a domain rule, and a chain

GenerateInsight ├─ build InsightSubject │ (summary, genres, comments) ├─ InsightPromptComposer │ ← a DOMAIN service └─ provider.generate(request) ← a PORT FallbackInsightProvider ├─ HuggingFace (needs a token) └─ heuristic (always answers)

The rule (what an insight may be based on) lives in the domain. The vendor lives outside, behind a port.

Adding a vendor is one class plus one registry line. No use case, port or test double changes.

Prompt text as domain is the debatable part — the rule it encodes is not.

12 / 18

Failure is a first-class outcome

  • InsightResult reports provider, degraded, cached and notes.
  • The UI says “via heuristic — offline fallback”. No pretending.
  • 429 is reported immediately and the chain moves on — degrading fast beats waiting.
  • Catalogue retries transport errors only, never a 500 (that is an answer).
  • Upstream errors are normalised in the adapter; no httpx exception reaches a use case.

Caching without a stampede

AsyncTtlCache.get_or_create takes a per-key asyncio lock: 25 concurrent identical requests trigger one upstream call. Asserted in test_cache.py.

  • Catalogue reads: TTL 300s — TVMaze is public and rate-limited.
  • Insights: TTL 900s keyed on the prompt hash. Regenerate bypasses with ?refresh=true.

14 / 18

Where it would break, and why I built it this way anyway

  • Cache is per process. The asyncio lock does not cross replicas: N pods = N upstream calls. Redis is the fix.
  • Migrations in the entrypoint. alembic upgrade head on every replica can race; production moves it to a release job.
  • Coverage is not quality. The domain is now mutation-tested (226 of 335 mutants killed, ~68%); property testing is still missing.
  • Auth is a guest cookie by design. httpOnly, SameSite=Lax; production wants OIDC, and identity is already isolated.

Each of these is a documented trade-off (docs/TRADEOFFS.md), not an accident.
